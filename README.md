# Velocity-file-share
This program allows users to effortlessly share any file under 200gb* in a lightweight platform

It works by creating a web socket with a server that allows users to automatically send a compressed file (gzip) and places it in temporary storage within the server. Next the user goes online and it automatically sends a decompressed version whilst the file is deleted in the server, this allows for high speed transfer of files. This platform supports any file type.

*Only with no active users; expect less
